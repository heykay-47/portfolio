# Portfolio

A personal portfolio with an optional arcade experience alongside its ordinary presentation.

## Language

**Arcade mode**:
An optional, reversible version of the homepage presented as a vertical shoot-’em-up instead of the normal page.
_Avoid_: Game page, separate game site

**Arcade launcher**:
The floating homepage control that invites visitors to enter arcade mode.
_Avoid_: Controller

**Encounter**:
A short, finite play session within arcade mode, comprising three waves and a final alien craft.
_Avoid_: Endless run

**Portfolio motif**:
A recognizable visual family from a major homepage section, such as project cards, badges, images, or borders, represented in arcade mode.
_Avoid_: Generic game skin
